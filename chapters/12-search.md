# Issue #12: 検索機能

151匹の中から目的のポケモンを素早く見つけられるようにします。

検索は**DBに対して**行います。Issue #3 で `name` `name_ja` にインデックスを張ったのは、
この章のためです。

## 1. この章でやること

- 一覧画面に検索フィールドを配置する
- 名前の部分一致と、図鑑番号での検索に対応する
- 検索は DB に対して行う（メモリ上のリストをフィルタしない）
- 入力のたびに検索が走らないようデバウンスをかける
- タイプでの絞り込みを追加する

## 2. 着手前に読む

- [Issue #12](https://github.com/sghh02/pokedex-android-kadai/issues/12) — **実装内容と受け入れ条件の正はこちら**。この章はそれを読む順番と、つまずきやすい点を補うものです
- [詳細設計](https://sghh02.github.io/pokedex-android-kadai/#03_詳細設計) — 検索のシーケンス

## 3. つまずきどころ

- **1文字打つたびにクエリを投げないこと。** デバウンス（300ms程度）を挟みます。入れないと入力がカクつきます
- 大文字・小文字を区別しない検索にすること。`SQLite` の `LIKE` は ASCII では既定で区別しませんが、実データで確認してください
- 検索文字列を消したら全件に戻ること。ここを忘れると「検索したら戻れないアプリ」になります
- 0件のときに真っ白な画面を出さない。「該当なし」と伝えます
